### Task 1.1 – Trace one activity using IPOS

**Activity:** Typing and saving a document

| Stage       | What happens in your example                    | Possible hardware / component |
|-------------|-------------------------------------------------|-------------------------------|
| Input       | I type text using the keyboard                  | Keyboard                      |
| Processing  | Computer processes the typed text               | CPU and Memory                |
| Output      | Text appears on the screen                     | Monitor                       |
| Storage     | I save the document                             | SSD / Hard Disk               |
